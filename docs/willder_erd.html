Tenant root: every table hangs off ORGS via org_id (tenant isolation). Access control: SCOPES (ltree tree) + GRANTS + ROLES + agent CAPABILITIES. Link to memory: ACCOUNTS and CONTACTS carry entity_id pointing to a Neo4j entity.

Neo4j — memory graph (via Graphiti)

graph LR
    EP["Episode
raw source, embedding, valid_at"]
    EN["Entity
person / company / deal
name_embedding, created_by"]
    EN2["Entity"]
    CM["Community"]
    PG[("Postgres
contacts / accounts")]

    EP -->|MENTIONS| EN
    EN -->|"FACT (subject → object)
valid_at · invalid_at · confidence · source_event_ids · created_by"| EN2
    EN -->|RELATION| EN2
    CM -->|HAS_MEMBER| EN
    PG -. "entity_id" .-> EN

    classDef pg fill:#dbe9ff,stroke:#7aa7e6;
    classDef node fill:#f1e2f7,stroke:#c08fd6;
    class EP,EN,EN2,CM node;
    class PG pg;

Graph model (not relational): Episode nodes are raw sources; Entity nodes are the graph nodes; FACT and RELATION are directed edges between entities (facts are bi-temporal + carry provenance and created_by); Community clusters entities. Vectors live here (Neo4j), not in Postgres. The two databases join only at entity_id.
