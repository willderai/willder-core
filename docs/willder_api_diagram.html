Willder — API Routes Map

Next.js route handlers, grouped by resource. Every route is tenant-scoped + access-checked.

Client→ Clerk auth→ Access check · check()→ Route handler→ Service→ Neon / Neo4j / Cache→ Response

Long ops (async ↻) hand off to Inngest and return a job id → poll /api/runs/:id. Inbound events arrive at /api/webhooks.

GET read POST create / action PATCH update DELETE remove ↻ async memory gate inbound
