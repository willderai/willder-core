Flow. Frontend sends tenant-scoped HTTP to the REST API, which calls Services. Access Control gates every Memory Service read before facts return (the single chokepoint). Services read/write the Cache and persist to the Database (Postgres for app + access policy, Neo4j for the memory graph). Agent Orchestration (Inngest, dashed = async) runs ingestion and agent tasks in the background and writes back to Services/DB. Services call External APIs for model inference (Groq/Qwen), sending (Unipile), data (Apollo, Exa, Firecrawl), auth (Clerk), billing (Stripe), email (Resend), and tracing (Langfuse). Inbound events arrive via /api/webhooks (Unipile replies, Stripe, Clerk).
